## To Add Your Own Cute Robot Image

### Step 1: Download a Cute Robot Image

Visit any of these FREE image sites:

1. **Flaticon** - https://www.flaticon.com
   - Search: "cute robot" or "ai assistant"
   - Download as PNG (512x512 or 1024x1024)
   - Free with attribution

2. **Freepik** - https://www.freepik.com
   - Search: "cute ai robot icon"
   - Download PNG format
   - Many free cute options

3. **Icons8** - https://icons8.com
   - Search: "robot cute" or "chatbot"
   - Download PNG (512px recommended)
   - Free for personal use

4. **Pixabay** - https://pixabay.com
   - Search: "robot icon cute"
   - Completely free, no attribution needed

### Step 2: Prepare the Image

1. Make sure the image is:
   - PNG format (with transparent background is best)
   - Size: 512x512 pixels (recommended)
   - File size: Less than 500KB
   - Cute and kid-friendly design

2. Rename the file to: `ai_tutor_cute.png`

### Step 3: Add to Your Project

1. Copy the image file
2. Paste it into: `app/src/main/res/drawable/`
3. Make sure the filename is: `ai_tutor_cute.png`

### Step 4: Update the Layout

After adding your image, I'll update the layout to use it. Just let me know when you've added the file!

The layout code will be:
```xml
<ImageView
    android:layout_width="60dp"
    android:layout_height="60dp"
    android:scaleType="fitCenter"
    android:src="@drawable/ai_tutor_cute"
    android:contentDescription="AI Tutor"/>
```

### Step 5: Rebuild

1. Build → Clean Project
2. Build → Rebuild Project
3. Run the app
