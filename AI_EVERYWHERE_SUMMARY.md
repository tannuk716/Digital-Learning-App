## 🎯 Where AI is Used

### 1. AI Tutor (Main Feature)
**Location**: AI Tutor button on student dashboard

**What it does**:
- Students ask any educational question
- AI provides detailed, age-appropriate answers
- Covers Math, Science, English, General Knowledge
- Adapts to student's class level

**Example**:
```
Student: "What is photosynthesis?"
AI: "Photosynthesis is how plants make their own food using sunlight, water, and carbon dioxide. The green color in leaves (chlorophyll) captures sunlight energy..."
```

---

### 2. Daily Speaking (Communication Skills)
**Location**: Communication Skills → Daily Speaking

**What it does**:
- AI evaluates spoken English responses
- Provides score, pronunciation, fluency, grammar feedback
- Gives personalized improvement suggestions
- Adjusts difficulty weekly (Week 1-4)

**Example**:
```
Question: "What is your favorite color?"
Student speaks: "My favorite color is blue"
AI: "✅ Score: 95%
     🗣️ Pronunciation: Excellent
     💬 Fluency: High
     📝 Grammar: Correct
     💡 Tip: Great job! Try adding why you like blue."
```

---

### 3. Pronunciation Trainer (Communication Skills)
**Location**: Communication Skills → Pronunciation Trainer

**What it does**:
- AI evaluates pronunciation accuracy
- Compares what student said vs. target word
- Provides specific pronunciation tips
- Gives phonetic guidance

**Example**:
```
Target: "Environment"
Student says: "Envirnment"
AI: "🎯 Score: 75%
     ✅ Accuracy: Good
     🔊 Phonetic Match: Medium
     💡 Tip: You missed the 'o' sound. Try: en-VY-ron-ment"
```

---

### 4. Vocabulary Builder (Communication Skills)
**Location**: Communication Skills → Vocabulary Builder

**What it does**:
- AI provides personalized explanations for answers
- Gives memory tricks to remember words
- Offers interesting facts about words
- Supportive corrections for wrong answers

**Example (Correct)**:
```
Word: "Opportunity"
Student: Selects correct answer ✅
AI: "Excellent! 🎉
     Fun fact: 'Opportunity' comes from Latin meaning 'toward the port'
     Memory trick: Think of opportunity as opening a DOOR to possibilities!"
```

**Example (Wrong)**:
```
Word: "Opportunity"
Student: Selects "Problem" ❌
AI: "Not quite right! 💪
     'Opportunity' is positive - it means a chance to do something good.
     Memory trick: When you see an OPPORTUNITY, say 'Oh! Port-unity!' - like finding a safe port."
```
